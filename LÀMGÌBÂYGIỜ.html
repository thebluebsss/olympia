🚀 Setup Multiplayer Game

4 người chơi cùng lúc - Real-time với Pusher

⏱️ Thời gian: 5-10 phút
💰 Chi phí: Hoàn toàn MIỄN PHÍ
👥 Kết quả: 4 người chơi cùng lúc, real-time!

1 Tạo tài khoản Pusher

Pusher cung cấp WebSocket miễn phí (100 connections = 25 phòng × 4 người)

👉 Tạo tài khoản Pusher
  1. Click "Sign up with GitHub" (nhanh nhất)
  2. Tạo app mới:
    • Name: olympia-game
    • Cluster: ap1 (Singapore - gần VN)
    • Tech: Vanilla JS + Node.js
  3. Click "Create app"

2 Copy API Keys

Sau khi tạo app, bạn sẽ thấy 4 giá trị quan trọng:

app_id: 1792566
key: 1a2b3c4d5e6f7g8h
secret: 9i0j1k2l3m4n5o6p
cluster: ap1
⚠️ Lưu ý: Copy cả 4 giá trị này, bạn sẽ cần chúng ở bước tiếp theo!

3 Cấu hình Local

Tạo file .env với thông tin từ Pusher:

PowerShell:

Copy-Item .env.local .env
notepad .env

Paste vào file .env:

PUSHER_APP_ID=1792566
PUSHER_KEY=1a2b3c4d5e6f7g8h
PUSHER_SECRET=9i0j1k2l3m4n5o6p
PUSHER_CLUSTER=ap1

VITE_PUSHER_KEY=1a2b3c4d5e6f7g8h
VITE_PUSHER_CLUSTER=ap1
💡 Tip: VITE_PUSHER_KEY và PUSHER_KEY giống nhau!

4 Test Local

Chạy server và test với 2 tab trình duyệt:

npm run dev
  1. Tab 1: Mở http://localhost:3000
    • Click "Tạo Phòng Mới"
    • Nhận mã phòng (ví dụ: ABC123)
  2. Tab 2: Mở http://localhost:3000 (tab mới)
    • Click "Tham Gia Phòng"
    • Nhập mã ABC123
✅ Nếu 2 tab thấy nhau trong danh sách người chơi → Thành công!

5 Deploy lên Vercel

Cấu hình environment variables trên Vercel:

  1. Mở Vercel Dashboard
  2. Chọn project olympia-44d9
  3. Vào Settings → Environment Variables
  4. Thêm 6 biến (chọn: Production + Preview + Development):
    PUSHER_APP_ID
    PUSHER_KEY
    PUSHER_SECRET
    PUSHER_CLUSTER
    VITE_PUSHER_KEY
    VITE_PUSHER_CLUSTER
  5. Click Save

Deploy:

npm run build
vercel --prod

6 Chơi với bạn bè! 🎉

Sau khi deploy thành công:

  • Người 1: Tạo phòng → Gửi mã cho bạn bè
  • Người 2, 3, 4: Join phòng với mã đó
  • Cả 4 người thấy nhau real-time
  • Host bắt đầu game khi đủ người
🎮 Game hỗ trợ đến 100 người chơi cùng lúc (25 phòng × 4 người)!

🔧 Gặp lỗi?

1. Console báo "Connection failed":

  • Mở F12 → Console xem lỗi chi tiết
  • Kiểm tra VITE_PUSHER_KEY đã đúng chưa
  • Thử đổi cluster từ ap1 sang us2

2. Build failed:

rm -rf node_modules
npm install --legacy-peer-deps
npm run build

3. Không thấy người chơi khác:

  • Clear cache: Ctrl+Shift+R
  • Restart server: Ctrl+C rồi npm run dev
  • Kiểm tra Pusher Dashboard → Debug Console
